# 📺 OpenCast-iOS

> **iOS (iPhone & iPad) için Tamamen Ücretsiz, Reklamsız ve Evrensel Ekran Yansıtma Uygulaması**

App Store'daki haftalık yüzlerce lira abonelik isteyen ve içi reklam dolu uygulamalara tepki olarak geliştirilmiş açık kaynaklı ekran yansıtma aracı.

---

## 🚀 Özellikler

- **%100 Ücretsiz & Sıfır Reklam:** Abonelik, reklam veya gizli ücret yok.
- **Evrensel Uyumluluk (Zero-Install):** Vestel Smart TV, LG webOS, Samsung Tizen, Android TV, Google TV, Philips, Windows PC, Mac ve konsollarla doğrudan uyumlu.
- **TV'ye Uygulama Yüklemeye Gerek Yok:** Televizyonunuzun dahili internet tarayıcısından tek tıkla bağlanır.
- **Düşük Gecikme & Donanım Hızlandırmalı:** Apple Metal ve VideoToolbox GPU hızlandırmasıyla 1080p Full HD akıcı aktarım.
- **Bellek Dostu:** Apple'ın 50 MB sınırının çok altında (~15-20 MB RAM) çalışır, asla çökme ve ısınma yapmaz.
- **Kumanda Dostu:** Vestel ve akıllı TV kumandalarında `OK` tuşuna basıldığında otomatik tam ekran modu.

---

## 🛠️ Nasıl Çalışır?

1. iPhone'unuzda **OpenCast** uygulamasını açın.
2. Ekranda görünen adresi (Örn: `http://192.168.1.45:8080`) Vestel televizyonunuzun (veya bilgisayarınızın) web tarayıcısına yazın.
3. Uygulamadaki **"Ekran Yansıtmayı Başlat"** butonuna dokunun.
4. TV kumandasından **OK** tuşuna basarak görüntüyü tam ekran yapın.

---

## 📦 Windows Üzerinden iPhone'a Yükleme (Mac Gerekmez)

1. Bu projeyi kendi GitHub hesabınıza yükleyin (veya Actions sekmesine gidin).
2. GitHub Actions otomatik olarak Apple macOS sunucularında `.ipa` dosyasını derler.
3. **Actions** sekmesinden `OpenCast-iOS-ipa` dosyasını bilgisayarınıza indirin.
4. Windows'ta **[Sideloadly](https://sideloadly.io/)** programını açın, iPhone 13'ünüzü USB ile bağlayıp `.ipa` dosyasını sürükleyin.
5. Uygulama telefonunuza yüklendi! Keyfini çıkarın.
